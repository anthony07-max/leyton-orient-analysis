# Manually transcribed data

Small files typed in by hand from public match pages, because the football-data.co.uk
CSV for 2026/27 (downloaded 19 Oct 2026) runs only to 10 Oct 2026.

| File | Content | Source (accessed 19 Oct 2026) |
|---|---|---|
| `league_one_results_2026-10-15_to_17.csv` | Scores (full time and half time) of the 12 League One matches played 15-17 Oct 2026 | [Football Web Pages, League One results, October 2026](https://www.footballwebpages.co.uk/league-one/fixtures-results/october) |
| `orient_v_blackpool_2026-10-17_match_stats.csv` | Team match statistics for Leyton Orient 2-0 Blackpool, 17 Oct 2026 | [Sky Sports match stats](https://www.skysports.com/football/leyton-orient-vs-blackpool/stats/7079498450254119232) |

Half-time scores are the bracketed figures on the Football Web Pages page, consistent with the goal times listed there.
The computed table after adding these results was checked against the Sky Sports League One
table (last updated 19 Oct 2026, 03:48): every team's played, won, drawn, lost, goals and points match.
